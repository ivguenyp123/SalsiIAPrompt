    css : retirer la balise de script litterale du commentaire de tokens.css
    
    css/core/tokens.css documentait l'ordre de chargement en recopiant les balises
    telles quelles, dont une balise de script. Le fichier est charge par les 26
    pages du produit.
    
    Un WAF qui inspecte les reponses voit une balise de script dans un corps servi
    en text/css et bloque : la reponse sort en 500. Comme la feuille est commune a
    toutes les pages, une seule regle les casse toutes -- et seulement la ou
    l'inspection existe, donc jamais en local. C'est exactement le symptome
    constate sur dev.
    
    Le commentaire decrit maintenant l'ordre en toutes lettres. Le CSS effectif est
    identique au caractere pres (4894 caracteres avant comme apres, comparaison
    faite hors commentaires) : aucun risque de regression visuelle.
    
    Verifie au navigateur : tokens.css est bien chargee, 128 variables definies,
    --bg-deep vaut toujours #0f0a1f, aucune erreur.
    
    Aucun autre fichier CSS du depot ne porte ce motif -- les 78 ont ete verifies.
