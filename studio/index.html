Le mode et l'executor viennent du registre, ils ne se saisissent pas. Une écriture est donc toujours exécutée par un module déterministe : l'invariant n'est pas une règle qu'on t'oppose, c'est une saisie impossible.

Critères — contrat vérifié à chaque exécution

Seules les cibles du registre sont proposées. Les cibles form portent sur la sortie elle-même : c'est ce qui rend la porte franchissable pour un agent de lecture.

Cas d'or — tests joués au banc d'essai

À ne pas confondre avec les critères. Un critère est vérifié à chaque exécution en production ; un cas d'or est un test de développement, rejoué à chaque montée de modèle. C'est lui qui rend la non-régression possible — sans cas d'or, un changement de version se constate en production.
